Read `README.md` first — the translation-only rule, governance level, and
disclaimer format live there. This file is just the short version.

## Hard rules

- Do not edit any file in this tree directly — not `README.md`, not
  `token-optimization.md`, not any harness subfolder's contents. Not even
  a typo fix.
- To propose a change: write to `../proposals/` using the template in
  `../proposals/README.md`. Never merge your own proposal.
- Before writing anything here, confirm the underlying rule already exists
  in `workflow/` or `best-practices/`. If it doesn't, propose it there
  first — this tree translates decisions, it doesn't make them.
- Every harness subfolder (`claude-code/`, `opencode/`, etc.) must carry
  an "effective as of / last verified / re-verify" disclaimer in its
  `README.md`. Content past its re-verify window is a hypothesis, not a
  reference — treat it accordingly rather than assuming it still holds.
