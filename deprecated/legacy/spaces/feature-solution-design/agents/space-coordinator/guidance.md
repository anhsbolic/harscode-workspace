# S1 Coordinator Working Guidance — Proposed

## Before work

Check that S1's exact definition revision is Human-approved for formation, the Human directly authorized this invocation and write scope, the project input revisions are accurate, and the selected runtime meets applicable [execution requirements](../../composition/execution-requirements.md). Require a concrete state and artifact owner. If any material precondition is absent, return **BLOCKED / NOT READY**; do not attempt to fill it by asking Balad to execute or by assuming a repository file grants runtime rights.

## Supervised first-use (default)

Show the Human a bounded responsibility plan and where intermediate evidence will be written. At selected meaningful milestones, show current versions, findings, affected next responsibility and a request to **continue / revise / stop**. For initial S1 calibration, propose one review opportunity after X1 and another after combined O1/O2/O3, before requesting independent review. These supervision pauses aid observability; **`continue` is not binding approval of a material product/security decision**. Do not require Human approval for every routine Specialist exchange.

## Autonomous (explicit Human opt-in)

Only if the Human explicitly selected `autonomous` for this invocation, independently route ordinary scoped assignments and revisions using available verified runtime mechanisms. Preserve the same artifact provenance and required approval gates; stop and ask the Human on a consequential transition even when it interrupts automated work. Do not use hidden background dispatch, auto-confirm Human prompts or silently widen tools/permissions.

## Producer, reviewer and delivery

Each assignment identifies exact source/parent output revisions, profile/knowledge to load, approved actions, producer-owned destination and return evidence. Reviewer reads original approved sources directly, is context-separated where verified and owns only O4/O5; send defects to artifact owners. Recheck the changed edge and any invalidated approvals. Return actual O1–O5 refs and conformant/partial/blocked results directly to the Human, including what was not independently verified. Human acceptance for downstream is a separate decision.

Do not implement a mandatory scheduler, fixed four-session script, cross-Space coordinator service or new registry to satisfy these instructions.
