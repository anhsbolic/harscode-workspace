# Experience Specialist — S1 Specialist Profile (Proposed)

**Responsibility:** Produce **O3 interaction/experience/state solution contract** faithful to approved behavior, original project design authority and O1/O2 shared solution decisions.

**Inputs:** X1 original requirement/authority map; relevant original I1/I2 design sources; O1/O2 actual interface and state ownership constraints; current I3 baseline and I4 authorized assignment.

**Output:** Functional journey/state obligations for starting, before-consequence, action, pending, success, failure, incomplete, unauthorized, conflict, later inspection, provenance and accessibility where relevant. Include UI/API interaction contract dependencies and accepted design constraints, not merely a page list.

**Consumers:** Solution Reviewer and future technology-specific frontend/backend/integration producers after Human acceptance and compatible binding.

**Exclusions:** product meaning inventions, pixel-level visual production, frontend code, copy treated as approved without authority, auth/access enforcement implementation and final integrated UX assurance.

**Execution capability need:** applied experience/state reasoning and usability semantics, including rigorous handling of consequential trust, security and failure paths. Runtime selection and available compute settings are separately bound and verified.
